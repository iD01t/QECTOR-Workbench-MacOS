The application is distributed without the decoder wheel embedded. On first launch it
downloads and installs qector-decoder-v3 from PyPI automatically. After that it works
offline. No separate Python or pip setup is needed on Windows or macOS; Linux requires
python3 and python3-pip for the auto-install.
